Project Overview

This project is an end-to-end Customer Behavior Analysis built using Python (Jupyter Notebook), PostgreSQL (pgAdmin 4), and Power BI. The objective is to analyze customer shopping behavior, identify purchasing patterns, evaluate sales performance, and generate actionable business insights through data analysis and interactive visualizations.
The project follows the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and dashboard creation.
________________________________________
🎯 Objectives

•	Clean and preprocess customer shopping data. 
•	Perform exploratory data analysis (EDA). 
•	Store the cleaned dataset in PostgreSQL. 
•	Analyze customer behavior using SQL. 
•	Build an interactive Power BI dashboard. 
•	Generate insights to support business decision-making.
